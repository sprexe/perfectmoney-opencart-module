# Perfect Money Payment Module for OpenCart 4.x

Perfect Money payment integration module for OpenCart 4.x.

## Compatibility

- OpenCart 4.x

## Module Package

The module package is included in this repository:

`perfectmoneyoc_4.ocmod`

## Installation

1. Download the module package from this repository.
2. Log in to the OpenCart Administrator panel.
3. Go to **Extensions → Installer**.
4. Upload the module package.
5. After installation, go to **Extensions → Extensions**.
6. Select the **Payment** extension type.
7. Find **Perfect Money** and install/enable the extension.
8. Configure the Perfect Money settings according to your account.

## Features

- Perfect Money payment integration
- OpenCart 4.x compatible
- Administrator configuration
- Payment processing through Perfect Money
